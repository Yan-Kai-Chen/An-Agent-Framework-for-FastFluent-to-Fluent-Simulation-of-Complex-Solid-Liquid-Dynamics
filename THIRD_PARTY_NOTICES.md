# Third-Party Notices

This repository separates public benchmark references from project-owned
code and synthetic data.

- TMBWG/NASA backward-facing step page:
  `https://tmbwg.github.io/turbmodels/backstep_val_sst.html`, accessed
  2026-07-23. Used for BM02 source identity and matched SSTm reference
  values.
- Ghia, Ghia and Shin, Journal of Computational Physics 48, 387-411
  (1982), DOI `10.1016/0021-9991(82)90058-4`. Used for BM04 and RP01
  centreline references.
- Schaefer et al., *Benchmark computations of laminar flow around a
  cylinder* (1996), DOI `10.1007/978-3-322-89849-4_39`. Used for RP02
  DFG 2D-2 reference quantities.
- BM01 and BM03 are public benchmarks defined in this work. Their
  analytical/reference-generation methods are included with the public
  validation code.

External reference data is not relicensed as project-owned Apache-2.0
data. Each reference file must retain its source identity and usage
note.
